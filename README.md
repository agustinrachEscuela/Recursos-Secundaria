# Recursos-Secundaria
# </> Aula de Programación

Sitio web educativo desarrollado para acompañar el aprendizaje de Programación en la escuela secundaria.

El sitio reúne contenidos teóricos, ejemplos prácticos y ejercicios organizados por año y por unidad, permitiendo que los estudiantes puedan consultar el material desde cualquier dispositivo.

## 🌐 Sitio web

La página está publicada mediante GitHub Pages.

> Agregar aquí la URL del sitio cuando esté publicada.

## 🧩 Estructura del sitio

Cada año contiene diferentes unidades.

Dentro de cada unidad se encuentran tres secciones:

### 📖 Teoría

Explicaciones de los conceptos trabajados en clase.

### 💻 Ejemplos

Fragmentos de código que permiten observar cómo se aplican los conceptos.

### ✏️ Práctica

Ejercicios para resolver y poner en práctica los contenidos.

Los ejercicios cuentan con un botón **"Ver solución"**, que permite mostrar u ocultar una posible resolución.

---

## 🛠️ Tecnologías utilizadas

El proyecto está desarrollado utilizando tecnologías web básicas:

- HTML5
- CSS3
- JavaScript

No requiere servidor ni base de datos para funcionar.
